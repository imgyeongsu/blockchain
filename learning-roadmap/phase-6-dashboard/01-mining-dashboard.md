# Phase 5: 채굴 성과 대시보드 (Mining Dashboard)

> **Phase 5: Dashboard**
> **목적:** JackpotChain 채굴 성과를 시각화하는 Power BI 대시보드 구축
> **도구:** Python (데이터 파이프라인) + Power BI Desktop (시각화)
> **대상:** 인사직무 취업 포트폴리오 - 데이터 분석 역량 증명

---

## 🎯 프로젝트 목표

블록체인 채굴 데이터를 **비기술 직군도 이해할 수 있는 KPI 대시보드**로 시각화한다.

> "블록체인 프로젝트에 참여하면서, 채굴 성과 데이터를 정의하고
>  파이프라인을 구축해 대시보드로 제공한 경험"

## 📊 데이터 구조 (CSV 스키마)

### mining_stats.csv

| 컬럼 | 타입 | 예시 | 설명 |
|---|---|---|---|
| `block_height` | INT | 1042 | 블록 번호 |
| `timestamp` | DATETIME | 2025-02-19 14:30:00 | 채굴 완료 시각 |
| `mining_time_sec` | FLOAT | 13.4 | 채굴 소요 시간 (초) |
| `nonce_attempts` | INT | 284512 | nonce 시도 횟수 |
| `difficulty` | INT | 4 | 난이도 (앞자리 0 개수) |
| `reward_jack` | FLOAT | 50.0 | 획득 보상 (JACK) |
| `tx_count` | INT | 7 | 블록 내 트랜잭션 수 |
| `is_fork` | BOOL | False | 포크 발생 여부 |
| `block_hash_prefix` | STRING | 0000a1b2 | 블록 해시 앞 8자리 |

## 🖥️ 대시보드 화면 설계

```
┌─────────────────────────────────────────────────────────┐
│  JackpotChain 채굴 성과 대시보드         최종 갱신: 14:32 │
├─────────────────┬──────────────┬────────────────────────┤
│  총 채굴 블록   │  누적 보상   │  평균 블록 타임         │
│    1,042        │ 52,100 JACK  │     14.8초              │
│  (목표: 15초)   │              │  ✅ 정상 (목표 15초)    │
├─────────────────┴──────────────┴────────────────────────┤
│  시간대별 채굴 블록 수 (막대 차트)                        │
│  → 채굴 활동이 활발한 시간대 파악                         │
├────────────────────────┬────────────────────────────────┤
│  난이도 변화 추이 (선형)│  블록 타임 분포 (히스토그램)   │
│  → 50블록마다 조정     │  → 15초 기준 편차 확인         │
├────────────────────────┴────────────────────────────────┤
│  최근 채굴 블록 목록 (테이블)                             │
│  block_height | timestamp | mining_time | reward | fork  │
└─────────────────────────────────────────────────────────┘
```

## 📈 KPI 정의

| KPI | 계산 방법 | 목표값 | 의미 |
|---|---|---|---|
| 평균 블록 타임 | `AVG(mining_time_sec)` | 15초 | PoW 안정성 |
| 채굴 성공률 | `채굴 블록 수 / 전체 시도` | - | 효율성 |
| 포크율 | `is_fork=True 비율` | ~13% 이하 | 네트워크 안정성 |
| 누적 보상 | `SUM(reward_jack)` | - | 채굴 수익 |
| 난이도 조정 주기 | `50블록마다` | 12.5분 | 정상 동작 확인 |
