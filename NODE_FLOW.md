# JackpotChain 노드 실행 흐름

## 실행 명령어

```bash
python -m jackpotchain.cli.main node --port 8333 --rpc-port 8332 --data-dir ./data --mine --address <주소>
```

## 피어 연결 흐름

```
┌──────────────────────────────────────────────────────────────────────────┐
│                        피어 연결 프로세스                                  │
└──────────────────────────────────────────────────────────────────────────┘

    내 노드                                          상대 피어
       │                                                 │
       │  ──────────  TCP 연결  ──────────────────────► │
       │                                                 │
       │  ══════════  VERSION  ═══════════════════════► │
       │    (내 높이, 프로토콜 버전, user_agent)         │
       │                                                 │
       │  ◄═════════  VERSION  ═══════════════════════  │
       │    (상대 높이, 프로토콜 버전, user_agent)       │
       │                                                 │
       │  ══════════  VERACK  ════════════════════════► │
       │                                                 │
       │  ◄═════════  VERACK  ════════════════════════  │
       │                                                 │
       │           *** 핸드셰이크 완료 ***               │
       │                                                 │
       │  (상대 높이 > 내 높이?)                         │
       │     └─ Yes: 블록 동기화 시작 (IBD)             │
       │                                                 │
       │  ══════════  GETBLOCKS  ═════════════════════► │
       │    (block_locator: 내가 가진 블록 해시들)       │
       │                                                 │
       │  ◄═════════  INV (block)  ═══════════════════  │
       │    (내가 없는 블록 해시 목록)                   │
       │                                                 │
       │  ══════════  GETDATA  ═══════════════════════► │
       │    (원하는 블록 해시)                           │
       │                                                 │
       │  ◄═════════  BLOCK  ═════════════════════════  │
       │    (블록 데이터)                                │
       │                                                 │
```

## 파일별 역할

### 진입점
| 파일 | 역할 |
|------|------|
| `cli/main.py` | CLI 엔트리포인트, 인자 파싱, 컴포넌트 초기화 |

### 네트워크
| 파일 | 역할 |
|------|------|
| `network/node.py` | P2P 노드, 메시지 송수신, 연결 관리 |
| `network/peer.py` | 피어 정보, PeerManager |
| `network/protocol.py` | 메시지 타입 (VERSION, INV, BLOCK 등) |
| `network/discovery.py` | 피어 발견 (DNS 시드, 캐시) |
| `network/nat.py` | NAT 포트 매핑 (PCP/NAT-PMP) |

### 합의
| 파일 | 역할 |
|------|------|
| `consensus/chain.py` | 블록체인 관리, Fork 처리, Reorg |
| `consensus/miner.py` | PoW 채굴, 블록 템플릿 |
| `consensus/difficulty.py` | 난이도 조정 |

### 핵심
| 파일 | 역할 |
|------|------|
| `core/block.py` | Block, BlockHeader |
| `core/transaction.py` | Transaction, TxInput, TxOutput |
| `core/utxo.py` | UTXO Set |

### API
| 파일 | 역할 |
|------|------|
| `rpc/server.py` | JSON-RPC API 서버 |
| `wallet/wallet.py` | 키 관리, TX 생성 |

### 로또
| 파일 | 역할 |
|------|------|
| `gacha/game.py` | 로또 게임 로직 |
| `gacha/service.py` | 로또 서비스 (RPC 연동) |
| `script/standard.py` | Commit/Claim 스크립트 |

## 메시지 프로토콜

| 메시지 | 방향 | 용도 |
|--------|------|------|
| `VERSION` | 양방향 | 핸드셰이크 시작, 버전/높이 교환 |
| `VERACK` | 양방향 | 핸드셰이크 확인 |
| `INV` | 양방향 | 보유 블록/TX 알림 |
| `GETDATA` | 요청 | 블록/TX 데이터 요청 |
| `BLOCK` | 응답 | 블록 데이터 전송 |
| `TX` | 양방향 | 트랜잭션 전파 |
| `GETBLOCKS` | 요청 | 블록 해시 목록 요청 (동기화) |
| `ADDR` | 양방향 | 피어 주소 공유 |
| `GETADDR` | 요청 | 피어 주소 요청 |
| `PING/PONG` | 양방향 | 연결 유지 |

## 초기화 순서 요약

```
1. cli/main.py          → 인자 파싱
2. Blockchain()         → 제네시스 블록 생성 (또는 디스크에서 로드)
3. Mempool()           → 미확인 TX 풀
4. Wallet()            → 키 로드
5. Node()              → P2P 노드
   └─ PeerDiscovery    → 피어 발견 (DNS/캐시)
6. RPCServer()         → HTTP API
7. node.start()        → TCP 서버 + 연결 태스크
8. rpc.start()         → HTTP 서버
9. mining_task()       → 채굴 루프 (옵션)
```
