# JackpotChain 사용법

---

## 실행 방법
### cmd

### 1. Simple 모드 (초보자용)
```bash
jackpotchain
```
- 지갑 자동 생성/로드
- 노드 자동 시작 + 채굴 자동
- 송금 / POT 교환 / 로또 / 당첨이력 메뉴

### 2. 고급 TUI 모드
```bash
jackpotchain tui
```
- 6개 탭: Dashboard, Wallet, Mining, Lotto, History, Network
- 다중 지갑 관리, 채굴 제어, 피어 모니터링

### 3. 노드 직접 실행 (CLI)
```bash
# 노드 + 채굴
jackpotchain node --mine --address 지갑주소

# 노드만 (채굴 없이)
jackpotchain node

# 포트 지정
jackpotchain node --port 9777 --rpc-port 9776 --mine --address 지갑주소

# 시드 노드로 실행
jackpotchain node --seed-node --mine --address 지갑주소
```

### 4. RPC 명령어 직접 실행
```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"명령어","params":[파라미터],"id":1}'
```
- 노드가 실행 중이어야 사용 가능 (3번 참고)
- 아래 전체 명령어 목록 참고

## RPC 명령어 목록

> 엔드포인트: `http://127.0.0.1:9776` | 프로토콜: JSON-RPC 2.0

## Blockchain

### getblockchaininfo
블록체인 상태 조회

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getblockchaininfo","params":[],"id":1}'
```

**응답**: `{ chain, blocks, bestblockhash, difficulty, mediantime, verificationprogress, chainwork }`

### getblockcount
현재 블록 높이

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getblockcount","params":[],"id":1}'
```

**응답**: `int`

### getbestblockhash
최신 블록 해시

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getbestblockhash","params":[],"id":1}'
```

**응답**: `str (hex)`

### getblockhash
높이로 블록 해시 조회

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getblockhash","params":[100],"id":1}'
```

**응답**: `str (hex)`

### getblock
블록 상세 조회 (verbosity: 0=hex, 1=JSON, 2=JSON+TX상세)

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getblock","params":["블록해시", 1],"id":1}'
```

**응답**: 블록 객체

### getrecentblocks
최근 블록 요약 (대시보드용)

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getrecentblocks","params":[10],"id":1}'
```

**응답**: `[{ height, difficulty, nTx, lotto_digit }, ...]`

## Lotto (온체인 로또)

### getlottoinfo
로또 시스템 정보

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getlottoinfo","params":[],"id":1}'
```

**응답**: `{ system, pool_balance, next_jackpot, total_entries, pending_commits, digit_count, comparison_blocks, prize_table }`

### getjackpotpool
잭팟 풀 상태

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"getjackpotpool","params":[],"id":1}'
```

**응답**: `{ balance, next_jackpot, total_entries, total_collected, snapshot_count }`

### lottocommit
로또 참여 (Commit TX 생성, 1 POT 필요)

```bash
# 직접 숫자 선택 (0~15, hex 한 자리씩 6개)
curl -X POST http://127.0.0.1:9776 -d '{"method":"lottocommit","params":[[10,3,15,7,0,12]],"id":1}'

# 랜덤 숫자
curl -X POST http://127.0.0.1:9776 -d '{"method":"lottocommit","params":[],"id":1}'
```

**응답**: `{ success, chosen_numbers, chosen_hex, tx_id, comparison_blocks, message }`

### lottocheckresult
로또 결과 확인

```bash
curl -X POST http://127.0.0.1:9776 -d '{"method":"lottocheckresult","params":["TX_ID_HEX"],"id":1}'
```

**응답 (대기중)**: `{ success, status:"pending", blocks_remaining }`
**응답 (당첨)**: `{ success, status:"win", chosen_numbers, result_digits, matches, prize_rank, payout_jack, paid }`
**응답 (낙첨)**: `{ success, status:"lose", chosen_numbers, result_digits, matches }`

### listlottocommits
로또 커밋 목록

```bash
# 전체
curl -X POST http://127.0.0.1:9776 -d '{"method":"listlottocommits","params":[],"id":1}'

# 특정 주소
curl -X POST http://127.0.0.1:9776 -d '{"method":"listlottocommits","params":["X4qg3ryi66zEu9S35iEtH8EUQ1T7M4kf8d"],"id":1}'
```

**응답**: `[{ tx_id, chosen_numbers, chosen_hex, commit_height, status, payout_block, blocks_until_payout, comparison_blocks }, ...]`

**status 값**:
- `pending_mine` — 채굴 대기 (아직 블록에 미포함)
- `pending` — 비교 블록 생성 대기 중
- `ready` — 결과 확인 가능 (N+28 도달)
